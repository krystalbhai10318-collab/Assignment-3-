## Overview
This lab trains a beginner-friendly **dense neural network (4-8-4-1)** to classify cyber activity as **Normal (0)** or **Attack (1)** from four numeric features, then compares it with an explainable **Decision Tree**.

| Feature | Meaning |
|---|---|
| `failed_logins` | Number of failed login attempts |
| `login_hour` | Hour of login (0–23) |
| `new_device` | 1 if the device was never seen before, else 0 |
| `data_transfer_mb` | Data transferred in the session (MB) |

## Results (seed = 42)
| Metric | Value |
|---|---|
| Train / test shapes | (75, 4) / (25, 4) |
| Final training accuracy | 86.67 % |
| Final validation accuracy | 73.33 % |
| **Neural network test accuracy** | **88.00 %** (loss 0.4761) |
| **Decision Tree test accuracy** | **92.00 %** |

**New-record predictions**

| failed_logins | login_hour | new_device | data_transfer_mb | NN probability | NN | Decision Tree | Agreement |
|---|---|---|---|---|---|---|---|
| 0 | 11 | 0 | 35 | 0.404 | Normal | Normal | Agree |
| 7 | 1 | 1 | 250 | 0.828 | Attack | Attack | Agree |
| 2 | 23 | 1 | 850 | 0.603 | Attack | Attack | Agree |

**Conclusion:** the Decision Tree is slightly more accurate and fully explainable, so for this small numeric table the simpler model is preferable. The neural network shows no strong overfitting; the modest train/validation gap is mostly due to the tiny validation set (15 rows).

## Notes
- The dataset is **synthetic** (generated by `src/generate_dataset.py` with a fixed seed) because the original `simple_cyber_activity.csv` was not supplied. If your instructor gave you the official file, replace `data/simple_cyber_activity.csv` with it and re-run; the numbers in this README will then differ.
- Exact TensorFlow results may vary slightly between versions and hardware.
- Normalization uses a scaler fitted on **training data only** to avoid data leakage; the Decision Tree uses unscaled features.
